前言#

debootstrap 是 debian/ubuntu 下的一个工具，用来构建一套基本的系统(根文件系统)。比正常发行版的体积小的很多，但是比自己 busybox 搭的功能更全，比 buildroot 更快，并且因为是基于发行版的，所以几乎没有各种奇怪的依赖问题很适合进行嵌入式文件系统的制作。

下面是基于ARM64平台进行构建Debian 12的基础文件系统。

安装过程#

1. 安装必备工具#

sudo apt update
sudo apt install -y debootstrap qemu-user-static

2. 第一阶段构建#

mkdir -p rootfs
sudo debootstrap --arch=arm64 --foreign bookworm ./rootfs http://deb.debian.org/debian/

其中需要解释的是：

foreign：告知 debootstrap 当前架构与目标架构不同，此阶段只下载和解压包，不执行目标架构的脚本（第二阶段来做）。

bookworm：指定发行版的代号

3. 第二阶段构建#

sudo cp /usr/bin/qemu-aarch64-static ./rootfs/usr/bin/
sudo chroot ./rootfs
/debootstrap/debootstrap --second-stage

这一步会在 arm64 模拟环境中配置基础系统，如设置软件源、安装基础包等。

3. 基础系统配置#

第二阶段构建完成之后可以进行一下基础系统的配置，比如新增用户，用户权限配置，基础软件安装，设置用户密码等等操作。

passwd root
apt update
apt install -y vim curl wget openssh-server sudo net-tools gcc g++ gdb

4. 完成与验证#

至此文件系统就做好了，这里我是用qemu来验证的，将文件系统复制进入空的 qemu 磁盘文件，然后启动 qemu

qemu-system-aarch64 \
        -M virt \
        -cpu cortex-a57 \
        -m 2G \
        -smp 1 \
        -kernel ./linux/arch/arm64/boot/Image \
        -drive file=./rootfs/debian/rootfs.img,format=raw,if=virtio \
        -append "root=/dev/vda rw console=ttyAMA0,115200 rootwait nokaslr" \
        -serial mon:stdio \
        -netdev user,id=net0,hostfwd=tcp::5555-:22 \
        -device virtio-net-pci,netdev=net0 \
        -nographic
