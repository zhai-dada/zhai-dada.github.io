算能BM1688：Linux下写入FIP.bin

前言#

因为每次编译SDK很慢，不能快速验证uboot的修改是否生效，所以想要在Linux下进行FIP.bin的烧录

FIP 组成#

build/scripts/atf.mk:196-209：最终用 fiptool.py genfip 打包成 fip.bin，包含：

  • CHIP_CONF：芯片配置 chip_conf.bin
  • BL2：FSBL/BL2（第一阶段引导）
  • DDR_PARAM：DDR 参数 ddr_param.bin
  • MONITOR：ATF/BL31（运行地址 0x100000000）
  • BL32：OP-TEE（0x100050000）
  • BLMCU：CV186x MCU 固件（0x05200000）
  • LOADER_2ND：U-Boot（BL33，即 u-boot-raw.bin）
  • compress lzma

fip.bin相当于一个bootloader了，BootROM->fip.bin->Kernel Image

FIP 烧录#

# 0) 确认 boot0 大小
cat /sys/block/mmcblk0boot0/size      # 512字节扇区数

# 1) 备份 boot0
sudo dd if=/dev/mmcblk0boot0 of=/root/boot0.backup bs=512 conv=fsync

# 2) 解除只读
sudo sh -c 'echo 0 > /sys/block/mmcblk0boot0/force_ro'

# 3) 写 fip.bin 到 boot0 偏移 0（主副本）
sudo dd if=fip.bin of=/dev/mmcblk0boot0 bs=512 conv=fsync

# 4) 可选：SDK 还会在 1MB（0x800 扇区）处写一份备份
sudo dd if=fip.bin of=/dev/mmcblk0boot0 bs=512 seek=2048 conv=fsync

# 5) 恢复只读并校验
sudo sh -c 'echo 1 > /sys/block/mmcblk0boot0/force_ro'
sync
sudo dd if=/dev/mmcblk0boot0 of=/tmp/boot0.read bs=512 count=840
cmp fip.bin /tmp/boot0.read
